- [Module 3: Caldova Bakery application](03.AppSetUp.md)

Module 3 contains a deliberately legacy ASP.NET Core 3.0 MVC bakery store with
SQL Server, product administration, a cart and demo checkout. Start with the
[application README](assets/module3/README.md) for Linux Docker setup.

This is an isolated workshop demo, not a production storefront. The application
has no authentication and uses an unsupported runtime. Do not expose it publicly
or enter real customer data.
